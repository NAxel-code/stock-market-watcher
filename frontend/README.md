# StockPulse Frontend

Next.js 14 App Router frontend for StockPulse (Real-Time Stock Market Watcher).

For full project architecture, environment setup, and deployment guides, please see the [Root README](../README.md).

## Local Development

```bash
npm install
npm run dev
```

Runs on [http://localhost:3000](http://localhost:3000).

## Testing

```bash
npm run test    # Vitest unit & component tests
npm run lint    # ESLint
npm run build   # Next.js production build check
```
